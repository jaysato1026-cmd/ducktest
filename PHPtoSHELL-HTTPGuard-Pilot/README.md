# PHPtoSHELL HTTP Guard — 測試環境試作

作者：王宥傑｜版本：2026.10.28｜狀態：**僅供隔離測試，不是正式防護部署**

發行者：Ailisa。正式簽章憑證身分尚未確認。

此獨立 EXE 在 HTTP 請求到達 PHP 前檢查 `multipart/form-data` 結構。預設只監聽 `127.0.0.1:18080`，將通過的請求轉送至 `127.0.0.1:8080`。它**不會變更**既有 8080 監聽、Windows Firewall、DNS、路由器、服務或 PHP 設定。既有用戶端若仍直接連 8080，完全不受此試作保護。

## 可重現的本機試跑

在受控測試主機上啟動 `PHPtoSHELL.HttpGuard.exe`，再對 `http://127.0.0.1:18080/_phptoshell/health` 執行唯讀健康檢查。預設不需要安裝 .NET Runtime；本包為 Windows x64 自含式單檔建置。若要改變測試用埠，在啟動前設定 `HTTPGUARD_LISTEN` 與 `HTTPGUARD_UPSTREAM` 為兩個不同的 HTTP 根網址。非 loopback 監聽必須額外明確設定 `HTTPGUARD_ALLOW_REMOTE_LISTEN=1`，但目前沒有 TLS 或驗證，不應以此直接對外提供服務。

## 現有檢查

- 同時最多處理 16 個代理請求，超額即回覆 503 與 `Retry-After: 1`，不在應用層排隊。健康檢查獨立於此名額，回覆 `pilot-ready` 與 `Cache-Control: no-store`；它只證明 Guard 可回應，不代表 PHP/Tomcat 上游健康。上游無法連線時代理請求回覆 502。
- 16 個受控請求占滿名額、第 17 個遭拒絕、健康檢查仍可用與釋放後恢復，均已在原始碼及自含式 EXE 合成測試中驗證。這是並行限制，不是每秒請求速率限制，也不限制所有底層 TCP 連線的資源。

- Kestrel 限制請求本文 16 MiB、總標頭 64 KiB、標頭數 100、請求列 8 KiB。
- 在轉送前完整讀取 multipart：最多 128 個 part、每個 part 最多 32 個標頭／8 KiB 標頭、欄位名稱最多 8 層中括號；不符合即回覆 400 或 413。
- 明確拒絕 WebSocket／Upgrade；保留一般請求的狀態碼、Cookie、查詢字串與回應本文。
- 固定上游主機，移除客戶端偽造的代理來源標頭與逐跳標頭；送往上游的 `X-Forwarded-For` 改為與 Guard 直接連線的 IP。

## 正式切換前的必要驗證

此試作尚未接入主 GUI，也沒有速率限制、TLS、服務安裝、自動更新、簽章、集中告警或高可用。Multipart 預讀會使用記憶體及暫存磁碟；16 MiB 是 HTTP 請求本文限制，**不會解壓內容編碼後再檢查**。目前 60 秒上游逾時與 Upgrade 拒絕可能影響合法長連線、串流與上傳。若上游能被直接連入，仍可繞過 Guard；若前面還有另一層代理，Guard 只能看到該代理的來源 IP。

正式導入須先確認真實 HTTP 入口、PHP worker 與供應商修補方式，收集合法上傳大小與 part 數，回放業務請求，量測延遲／記憶體／磁碟負載，驗證來源 IP 與 Cookie／重導向，設計 TLS、流量切換與快速撤回。此試作不能代替 PHP 修補，也不能宣稱已阻止所有 PHP2SHELL 攻擊鏈。

## 本機驗證記錄

待追查：新增網址編碼一致性檢查後，一次本機整合測試在四個並行上傳檢查失敗；增加每個請求的狀態碼／本文雜湊診斷後重跑通過，尚未取得失敗原因。這項間歇性問題仍未解決，不能據重跑通過宣稱穩定性驗收完成。

後續補充：128 part、8 層欄位與每 part 32 個標頭可通過，分別超出一個即在上游前拒絕。約 1 MiB 二進位上傳及四個並行上傳均比較本文 SHA-256。302 與 Location 原樣保留，代理不自行追蹤跳轉；逐跳回應標頭移除，Cookie 保留。此證據仍限合成流量，不表示業務負載驗收。

2026-10-28：.NET 9 Release 建置 0 error／0 warning；以假上游執行整合測試，確認正常 GET、表單、空白 POST、合法 multipart 可轉送；缺少 boundary、129 part、過長 part 標頭、過深欄位、chunked 超額與大於 16 MiB 的 Content-Length 會在上游前拒絕。路徑改寫、偽造來源標頭與非 loopback 啟動閘門亦通過。自含式 EXE 以相同測試重跑通過。測試僅涵蓋 loopback 與合成請求，不代表目標主機相容或商用驗收。
